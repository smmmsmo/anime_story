- [Decisions](decisions.md): only explicit confirmations become locked canon; currently none.
- [Open questions](open-questions.md): unresolved creative constraints.
- [Session log](session-log.md): dated summaries of discussions and changes.
- [Character template](templates/character.md) and [Story pitch template](templates/story-pitch.md).

Workflow: gather ideas → record alternatives → identify tradeoffs → choose a working preference (still reversible) → only when creator explicitly confirms, mark final canon in decisions.md. Don't erase superseded ideas; preserve them as options or archive.
